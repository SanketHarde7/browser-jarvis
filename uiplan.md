# 1. PRODUCT VISION

MAX is not another chatbot.

MAX should feel like an intelligent digital lifeform that happens to live inside your phone.

The interface should never resemble ChatGPT, Gemini, Claude, Perplexity, or any traditional messaging application.

Instead, the interface should create the illusion that the user is interacting with a conscious digital companion that continuously exists, even when it is not speaking.

The primary design goal is emotional connection.

The user should never feel like they are sending prompts to software.

Instead, they should feel like they are communicating with a living intelligence that listens, thinks, remembers, and responds naturally.

Every animation, transition, glow, particle, and movement should reinforce this illusion.

Nothing inside the interface should ever appear mechanical, robotic, or static.

Even when MAX is idle, the interface should subtly communicate that MAX is awake and aware.

Silence should never feel empty.

Instead, silence should feel alive.

# 8. FIRST IMPRESSION

When the application launches for the very first time, the user should immediately feel that this is fundamentally different from every AI assistant they have used before.

Avoid any onboarding screens.

Avoid tutorial carousels.

Avoid permission dialogs immediately on launch unless required.

The user should first experience the product emotionally before being asked for anything.

The first launch sequence should focus on building anticipation.

The interface should gradually reveal itself rather than appearing instantly.

The orb should slowly materialize from darkness as if intelligence is awakening.

The logo should fade into view after the orb has already begun breathing.

The background should come alive before any interactive elements appear.

The user should feel as though they have entered an existing digital environment rather than opened a mobile application.

# 9. LOADING EXPERIENCE (COLD START)

The loading experience should never feel like waiting.

It should feel like witnessing the birth of an intelligence.

The sequence should follow this timeline.

### Stage 1 — Darkness

Duration: ~400–600 ms

The screen begins nearly black, but not pure black.

A very subtle animated gradient is already moving in the background.

Tiny particles, almost invisible, drift slowly to hint that the environment is alive even before MAX appears.

No logo.

No spinner.

No progress bar.

Only atmosphere.

---

### Stage 2 — Energy Formation

Duration: ~800 ms

A faint point of blue light appears at the center of the screen.

This point should not blink into existence.

It should slowly increase in brightness.

As it brightens, microscopic particles begin moving toward it from all directions, as if gravity is pulling energy together.

The particles accelerate slightly as they approach the center and then dissolve into the light.

This creates the illusion that MAX is assembling itself from ambient energy.

There should be no harsh flashes or sudden movements.

Everything must feel calm and deliberate.

---

### Stage 3 — Orb Birth

Duration: ~1200 ms

The central light expands into a soft luminous sphere.

At first, it is only a diffuse glow.

Gradually, the plasma loops, nebula flow, and glass shell become visible one layer at a time.

The orb should feel like it is "coming online," not simply fading in.

Each visual layer should appear with a slight delay so the user subconsciously understands that the orb is a complex living system rather than a flat graphic.

The breathing animation should begin before the orb is fully visible, reinforcing the illusion of life.

---

### Stage 4 — Identity Reveal

Only after the orb is stable should the MAX wordmark fade in.

The subtitle ("Your AI Assistant") appears approximately 200 ms later.

The Settings icon should appear last with a soft upward fade, indicating that controls are secondary to the intelligence itself.

---

### Stage 5 — Interface Activation

The conversation card should gently rise from the bottom with a spring animation.

The input field should follow.

Finally, the microphone button should float into place with a subtle glow pulse, indicating that the system is now ready to listen.

At this point, the loading sequence is complete.

There should be no abrupt transition between the loading experience and the home screen.

The loading sequence should seamlessly transform into the idle state.

---

# IMPORTANT DESIGN RULE

At no point should the user ever see a traditional circular loading spinner.

MAX never "loads."

MAX "awakens."

This distinction is fundamental to the product's identity.

# 12. MOTION & ANIMATION SYSTEM

Animation is one of the defining characteristics of MAX.

Static interfaces feel like software.

Living motion creates the illusion of intelligence.

Every animation inside MAX should communicate purpose.

The user should never consciously notice animations.

Instead, they should subconsciously feel that the interface is alive.

The ultimate goal is for motion to become invisible.

When users describe MAX, they should say

> "It just feels alive."

instead of

> "It has nice animations."

If users notice animations more than the intelligence itself, the animation system has failed.

---

# MOTION PHILOSOPHY

Every movement answers one question.

Why did this move?

If there is no logical reason,

it should not move.

Animation exists to communicate

State

Attention

Energy

Emotion

Hierarchy

Continuity

Never animate for decoration alone.

---

# THE THREE LAWS OF MOTION

Every movement inside MAX follows these principles.

LAW 1

Everything has weight.

Cards have weight.

Buttons have weight.

The Orb has weight.

Particles have weight.

Nothing teleports.

Nothing instantly appears.

---

LAW 2

Everything has momentum.

When an element starts moving,

it accelerates naturally.

When it stops,

it decelerates naturally.

Abrupt stopping destroys realism.

---

LAW 3

Nothing exists in isolation.

If one object moves,

nearby lighting,

reflections,

glows,

and shadows should subtly respond.

Example

If the Orb slightly floats upward,

its glow should expand downward by a few pixels.

Its reflection should shift.

Nearby particles should adjust naturally.

This tiny interaction makes the entire interface feel like one physical environment.

```
src/

components/
    Orb/
    Background/
    Header/
    Input/
    Mic/
    Conversation/
    Settings/
    Shared/

hooks/

animations/

contexts/

services/

types/

utils/

constants/

assets/

pages/
```

Recommended libraries

- Framer Motion
- React Spring (optional)
- React Icons
- Zustand
- React Markdown
- React Syntax Highlighter
- Lenis (optional)
- GSAP (only if absolutely necessary)

Prefer custom components over UI frameworks.

# 25. Future Features

Design only.

Do not implement.

Include

- Memory Timeline
- Vision
- Camera
- Screen Understanding
- File Upload
- Multiple Agents
- Plugins
- Local Models
- Live Activities
- Dynamic Island
- Smart Notifications
- Desktop Companion
- Smart Widgets

# 26. Things NOT To Build

Avoid

- ChatGPT clone UI
- Material Design
- Neon Cyberpunk
- Heavy Gradients
- Glass Everywhere
- Floating Action Buttons
- Bottom Navigation
- Large Side Menus
- Excessive Cards
- Emoji-heavy UI
- Flashing Animations
- Complex Dashboards
- Multiple Accent Colors
- Cluttered Home Screen

The interface should remain calm, premium, and minimal.

---

# 27. Acceptance Checklist

The implementation is considered complete only if:

- Orb feels alive at all times
- Background never feels static
- Animations remain smooth
- No visible frame drops
- Voice states are instantly recognizable
- User understands current AI state without reading text
- Loading experience feels like awakening, not loading
- Motion feels natural and physically believable
- Glass components remain visually consistent
- The interface feels calm and premium
- Accessibility requirements are satisfied
- Performance targets are met
- Future screens can be added without redesigning the system

## Final Design Goal

MAX should never feel like an application.

It should feel like a calm, intelligent digital companion that lives inside the device.

Every visual decision, animation, interaction, and transition should reinforce the illusion that MAX is a living intelligence rather than software.
